# Синтетический тест «AI limit: annual upfront vs weekly trial»

Тест собран 7 ноября, чтобы показать ловушку сырого P2BB в чистом виде: вариант, который платит сразу, против варианта с триалом и недельными продлениями. Прогнан кодом вердикта из `feature/verdict-agent` без изменений.

## Как собран

`make_test.py` берёт офлайн-датасет Lumen (`adapty-seed-data-hack/data/offline`) и переносит 6 000 реальных пользователей датасета в новый тест на плейсменте `ai_limit_reached`, по 3 000 на руку:

| Рука | Состав | Откуда пользователи |
|---|---|---|
| `annual_upfront` | 10% покупают годовую подписку сразу ($49,99, без триала), 90% ничего не покупают | первая транзакция `annual` без оффера |
| `weekly_trial` | 35% начинают недельный триал (3 дня, потом $6,99 в неделю), 65% ничего не покупают | первая транзакция `weekly` с `free_trial` |

Транзакции пользователей не меняются: удержание, отмены и рефанды такие, какие они есть в датасете. Пользователи выведены из исходных флоу, поэтому калибровка, которая строится по пользователям вне теста, их не видит. Доли 10% и 35% подобраны так, чтобы на 60 днях победил триал, а в первые недели по полученным деньгам вёл годовой.

Правда по всей популяции руки, выручка на пользователя:

| Горизонт | `annual_upfront` | `weekly_trial` |
|---|---|---|
| 7 дней | $4,37 | $1,04 |
| 14 дней | $4,32 | $1,95 |
| 28 дней | $4,32 | $3,48 |
| **60 дней** | $4,32 | **$5,88** |
| 90 дней | $4,32 | $6,61 |

`run_synth.py`, горизонт 60 дней. Сырой P2BB здесь это вероятность, что `weekly_trial` лучше по полученной выручке; `p2bb_exp` то же по ожидаемой.

Сырой P2BB уверен в `annual_upfront` на 99,9% и больше каждый день с 3-го по 60-й. Он не исправляется с данными: пока тест идёт, в него каждый день приходят новые пользователи, у которых недельные платежи ещё не начались, и полученная выручка руки с триалом остаётся далеко позади. Вердикт по ожидаемой выручке с 14-го дня подтверждает настоящего победителя.

Разложение выручки на пользователя на 14-й день: `annual_upfront` $3,77 получено, продлений не ожидается; `weekly_trial` $1,01 получено, $1,29 ожидается от триалов, $3,30 от продлений. Guardrail по рефандам `ok` у обеих рук. Сегментов проверено 13, найдено 0. JSON: `synth_day7.json`, `synth_day14.json`, `synth_day28.json`.

## Что говорить честно

- Калибровка здесь идеальна по построению: тестовые пользователи взяты из той же популяции, что и пользователи вне теста, поэтому поведение триалов и продлений совпадает. В реальном приложении калибровка по истории может отличаться от поведения нового варианта. Этот тест показывает механику перекоса, а не точность калибровки.
- Доли покупателей по рукам выбраны руками, чтобы разница на 60 днях была заметной (36%). Транзакции при этом настоящие из датасета.
- При 300 пользователях в день к 28-му дню выборка превышает популяцию руки (3 000), повторы берут пользователей с возвращением, уверенность завышена.
- Горизонт 60 дней. На 90 днях разрыв в пользу триала ещё больше ($6,61 против $4,32).

## Как воспроизвести

```bash
git clone https://github.com/kpotehin/adapty-seed-data-hack
python eval/synthetic_test/make_test.py adapty-seed-data-hack/data/offline /tmp/synth
# в чекауте feature/verdict-agent, Python 3.11+
python eval/synthetic_test/run_synth.py <путь к репо с verdict_agent> /tmp/synth 100
# или обычный CLI:
VERDICT_DATASET=/tmp/synth python -m verdict_agent.cli offline "AI limit: annual upfront vs weekly trial" --day 14 --traffic 100
```
